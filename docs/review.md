# Course review

The opening audit reviewed the public overview and all nine lesson routes at 7c8feb1. Learners need to read a basic shell command. The review checked lesson prose, starter commands, console evidence, control labels, save feedback, and optional material against that starting point. The implementation also incorporated the concurrent Linux image download and startup cancellation published in 7fe1c0f.

The opening audit found four recurring problems. The starter pipeline command filtered out the writev() call the guest actually used to send its bytes. Some activities asked learners to compare results without naming the output or how to retrieve a previous run. The workbench showed output after a lesson or case change without identifying its source. The footer claimed browser saves succeeded even if storage failed.

The closing audit applied the same criteria to the revised workbench. Each lesson introduces the terms it needs and keeps the starter instructions, evidence to read and comparison visible. The Case selector restores the selected case’s output during the visit. Output identifies its case and command, and the run status identifies fixture preparation, interruption and the command’s exit status separately. The child lesson names the exact -f edit and keeps the previous trace available. The pipeline filter includes writev() so both pipe and terminal writes can be compared. Hints, worked diagnoses, previous traces and the shell have named disclosures. The page retains the existing browser storage keys for commands, notes and case selections. If saving fails, the current tab retains the work and can export it. Guest keyboard adapters are disabled so keyboard activation stays in the browser workbench.

The controlled examples use real strace inside the packaged Alpine x86 guest. Paths, permission rules and loopback services are fixtures. Timing is measured within the individual guest run. Functional checks verify the actions, trace evidence and behaviour described here. Learner understanding was not measured.
